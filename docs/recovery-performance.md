# Ordinary recovery profile

This historical H20 ordinary-recovery profile uses vLLM 0.29.0 / SGLang 0.5.20. It measures native preparation, copy and control observations with retained output and cleanup limits. Overlapping stage means cannot be subtracted from latency percentiles or used to prove a CUDA-kernel bottleneck.

The [immutable full report](https://github.com/feichai0017/orbitkv/blob/251f463d8997eff783871ab2820da83a13a97196/docs/recovery-performance.md) retains tables, exact commands,
artifact locations, failed controls and uncertainty. Use [performance methodology](performance.md)
for new comparisons and [compatibility](compatibility.md) for current support.
