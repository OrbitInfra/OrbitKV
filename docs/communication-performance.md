# Local communication measurements

Historical matched controls retain the initial engine-local Restore regression and subsequent idle-stream, descriptor-compaction, strided-DMA and layer-readiness improvements. Dense copy gains, small-payload overhead and complete serving latency have different scopes. The full report preserves rejected controls and all measured engine/build versions.

The [immutable full report](https://github.com/feichai0017/orbitkv/blob/251f463d8997eff783871ab2820da83a13a97196/docs/communication-performance.md) retains tables, exact commands,
artifact locations, failed controls and uncertainty. Use [performance methodology](performance.md)
for new comparisons and [compatibility](compatibility.md) for current support.
