# Qwen3-8B concurrent query ownership baseline

This historical Qwen3-8B cohort measures concurrent query ownership and burst behavior with fixed cache/query budgets. Correct bytes, retained source leases and bounded reservations are distinct from throughput, fairness and tail isolation. Its vLLM 0.29.0 / SGLang 0.5.20 profiles do not automatically qualify newer releases.

The [immutable full report](https://github.com/feichai0017/orbitkv/blob/251f463d8997eff783871ab2820da83a13a97196/docs/concurrent-performance.md) retains tables, exact commands,
artifact locations, failed controls and uncertainty. Use [performance methodology](performance.md)
for new comparisons and [compatibility](compatibility.md) for current support.
