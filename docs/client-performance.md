# Native client control-path measurements

This reviewed historical component cohort measures the native client control path with fixed workloads and local controls. It is not model-serving latency or a current-release native/OrbitKV/LMCache comparison. Setup, repeated polling, payload restoration and Python return-boundary timing require separate measurements.

The [immutable full report](https://github.com/feichai0017/orbitkv/blob/251f463d8997eff783871ab2820da83a13a97196/docs/client-performance.md) retains tables, exact commands,
artifact locations, failed controls and uncertainty. Use [performance methodology](performance.md)
for new comparisons and [compatibility](compatibility.md) for current support.
